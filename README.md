# ImageLab Pro - Лабораторная работа 3 (Вариант 16)

## Описание проекта
Графическое приложение для обработки цифровых изображений, реализующее:
1. Линейное контрастирование
2. Морфологические операции (эрозия, дилатация, открытие, закрытие)

## Минимальные требования
- Операционная система: Windows XP или выше
- Java Runtime Environment (JRE) версии 8 или выше
- 512 МБ оперативной памяти
- Разрешение экрана: 1024×768

## Установка и запуск

### Шаг 1: Подготовка
1. Скачайте архив с проектом
2. Распакуйте в любую папку на компьютере
3. Убедитесь, что установлена Java (проверьте командой `java -version`)

### Шаг 2: Сборка
Дважды щелкните по файлу `build.bat`
- Файл создаст папку `build` с скомпилированными классами
- Появится сообщение "Build complete!"

### Шаг 3: Запуск
Дважды щелкните по файлу `run.bat`
- Запустится графическое приложение

## Структура файлов

ImageLab_Project/
├── build.bat          # Скрипт сборки проекта
├── run.bat            # Скрипт запуска приложения
└── src/
    └── Main.java      # Исходный код приложения


## Функциональные возможности

### 1. Работа с изображениями
- Загрузка изображений (JPG, PNG, BMP, GIF)
- Просмотр оригинального и обработанного изображений
- Сохранение результатов обработки

### 2. Линейное контрастирование
- Настройка параметра контраста (a)
- Настройка параметра яркости (b)
- Формула: I_out = a × I_in + b

### 3. Морфологические операции
- Эрозия - уменьшение объектов
- Дилатация - увеличение объектов
- Открытие - эрозия + дилатация
- Закрытие - дилатация + эрозия
- Настройка формы ядра: квадрат, круг, крест
- Настройка размера ядра: от 3×3 до 15×15

### 4. Анализ изображений
- Гистограмма яркости
- Отображение размеров изображения
- Информация о цветовой модели

## Инструкция по использованию

### Основные действия
1. Нажмите кнопку "Загрузить" для выбора изображения
2. Для контрастирования используйте слайдеры "Контраст" и "Яркость"
3. Для морфологических операций выберите операцию, форму и размер ядра
4. Нажмите соответствующую кнопку "Применить"
5. Для сохранения результата нажмите "Сохранить"

### Рекомендации по тестированию

#### Для контрастирования:
- Используйте темные или малоконтрастные изображения
- Настройте параметры a и b для улучшения видимости

#### Для морфологических операций:
- Используйте бинарные изображения или изображения с текстом
- Экспериментируйте с разными размерами ядра

## Устранение неполадок

### Проблема: Приложение не запускается
**Решение:** Установите Java с официального сайта oracle.com/java

### Проблема: Изображение не загружается
**Решение:** Убедитесь, что файл не поврежден и имеет поддерживаемый формат

### Проблема: Ошибка при компиляции
**Решение:** Запустите `javac -version` для проверки установки компилятора
